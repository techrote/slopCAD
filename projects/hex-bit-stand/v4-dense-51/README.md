Current recommended high-capacity design.

- Layout: **6–7–8–9–8–7–6**
- Functional pocket: **7.0 mm AF**
- Pocket depth: **12.0 mm**
- Base: **1.0 mm**
- Lead-in: **0.6 mm high**, widening to **8.2 mm AF**
- Centre pitch: **8.8 mm**
- Row pitch: approximately **7.621 mm**
- Straight-section web: **1.8 mm**
- Minimum top lead-in web: **0.6 mm**
- Nominal outer wall margin: **2.4 mm**
- Envelope: approximately **84.6 × 62.12 × 13.0 mm**

The body retains the contoured outer profile, flared foot, recessed accent band, and top chamfer while using a much denser honeycomb lattice.

A variable-width/Arachne-style perimeter generator is recommended for the single-extrusion-width top webs.
