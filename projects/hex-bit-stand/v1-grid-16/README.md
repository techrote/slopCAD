# v1 — 16-pocket grid

Initial 4 × 4 hex-bit stand.

- Capacity: **16**
- Overall size: **52.8 × 52.8 × 18.0 mm**
- Functional pocket: **7.0 mm AF**
- Pocket depth: **12.0 mm**
- Lead-in: **0.6 mm**, opening to **8.2 mm AF**
- Pocket pitch: **10.8 mm**
- Floor below pockets: **6.0 mm**
- Outer top chamfer: **2.4 mm at 45°**

This version established the pocket fit and nozzle-friendly geometry but uses substantially more material than later revisions.
