# v2 — 13-pocket hex pattern

Reworked layout using a staggered 4–5–4 pocket cluster.

- Capacity: **13**
- Functional pocket: **7.0 mm AF**
- Pocket depth: **12.0 mm**
- Base/floor thickness: **1.0 mm**
- Lead-in: **0.6 mm**, opening to **8.2 mm AF**
- Outer chamfer: **1.8 mm at 45°**
- Overall size: approximately **57.0 × 35.47 × 13.0 mm**

The major changes from v1 are the hex-style arrangement and much thinner base.
